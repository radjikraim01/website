# Stick Figure Soccer

A simple stick figure soccer game built with HTML5 Canvas and JavaScript.

## How to Play

### Player 1 (Blue)
- **W**: Jump
- **A**: Move Left
- **D**: Move Right
- **Q**: Kick

### Player 2 (Red) / AI
- **Up Arrow**: Jump
- **Left Arrow**: Move Left
- **Right Arrow**: Move Right
- **P**: Kick

*Note: If no input is detected for Player 2, the AI will take over.*

## Features
- Realistic stick figure animations.
- Ball physics and kicking mechanics.
- Scoring system and goal detection.
- Simple AI for single-player mode.
